# VULNEX — сайт и прототип платформы

**Создавай смело. Защищай разумно.** VULNEX соединяет стартапы, которым нужна доступная проверка безопасности, с начинающими специалистами, которым нужна реальная практика.

**Сайт:** https://liberty74.github.io/vulnex/

## Как запустить

- **Локально, ИИ работает без интернета:** дважды щёлкнуть **ЗАПУСК.bat**. Он сам поднимет Ollama и откроет http://localhost:5190.
- **Опубликованный сайт с ИИ на своём компьютере:** запустить **ИИ_ДЛЯ_САЙТА.bat**. Он перезапустит Ollama с разрешением `OLLAMA_ORIGINS=https://liberty74.github.io`. Затем открыть сайт. Если браузер спросит доступ к устройствам в локальной сети, разрешите.
- Без Ollama на сайте работает всё, кроме ИИ: страницы, демо-данные, анализ кода по правилам.

## Деплой

Каждый push в `main` собирается GitHub Actions (`.github/workflows/pages.yml`) и публикуется на GitHub Pages.

## ИИ

- Работает через Ollama на этом компьютере.
- Локальные модели `qwen2.5:7b` и `llama3` работают без интернета, код стартапа никуда не уходит.
- Облачные модели Ollama Cloud (Gemma 4, GPT-OSS, Nemotron) включаются только по выбору, и интерфейс об этом предупреждает.
- На процессоре этого ноутбука локальная модель отвечает за 30–90 секунд. Правила анализа кода срабатывают мгновенно.
- Первая выбранная модель основная: она пишет черновики, проверяет отчёты и ведёт наставника. В анализе кода участвуют все выбранные модели.

## Честно о прототипе

- Сервера пока нет: проекты, отчёты и репутация хранятся в браузере. Кнопка «Сбросить демо» на странице «Мой путь» возвращает всё к началу.
- Всё с пометкой «демо» вымышлено: проекты, никнеймы специалистов, отчёты.
- Примеры кода в анализе учебные и намеренно уязвимые.
- ИИ выдаёт гипотезы. Подтверждает человек.
